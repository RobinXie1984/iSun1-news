# Independent global reader

Build with `npm run build` then `node scripts/build-independent.mjs`. Deploy the generated Worker through the owner's existing Cloudflare account. Do not publish operational account IDs or credentials.

The reader serves every original story, selection, language, theme, media asset and download from the reviewed local bundle. No ChatGPT/Sites request, font CDN or account login is needed for reading. Retain the original Sites project as a rollback and preserve its historical database. This initial reader collects no analytics; existing public measurement records are not reset or relabelled. Its Pulse reports unavailable evidence as UNKNOWN.

Keep `isun1.news` and `www.isun1.news` owned and stable. Before DNS cutover, inspect and preserve all current DNS records, verify the new runtime, retain exact rollback records, and use the existing domain account. Never weaken TLS, solve an unconfirmed CAPTCHA, expand credentials, buy a plan, or alter unrelated domains. Mainland and global access claims require real regional observations; a custom domain alone is not proof.

Update this reader from the same canonical daily build after a news release, without changing the editorial collection cadence. Do not publish private screening videos or feedback here.

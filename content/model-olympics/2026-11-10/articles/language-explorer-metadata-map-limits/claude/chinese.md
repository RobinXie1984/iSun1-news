# 柏林一幅地图，点亮数千种语言——每枚图钉背后，藏着什么？

2026年11月9日，谷歌研究院（Google Research）发文宣布，旗下的“语言探索器”（Language Explorer）以互动装置的形式，进入柏林通信博物馆（Museum für Kommunikation）的一场展览。展览名为《REAL TALK. Language. Power. World.》，意为“真话：语言、权力与世界”。语言探索器是一个免费公开的网站，供人浏览世界上数千种语言的资料：一幅缀满图钉的世界地图，一个搜索框，每种语言各有一页数据。执笔者是谷歌研究院两位从事语言技术的研究人员，Daan van Esch 与 Uche Okonkwo。网页之下，托着一座名为 LinguaMeta 的研究资料库。2024年5月，这两位与同事 Sandy Ritchie、Shikhar Vashishth、Emily Drummond 一道，在语言研究界的重要会议 LREC-COLING 上发表论文，介绍了它。故而2026年11月的新意，在于一项旧研究换了新舞台：一座原为科学家与工程师而建的数据库，如今立在了博物馆观众的面前。

放眼更大的背景，便知此事何以值得一谈。谷歌称，世上通行的语言在七千种以上，并以这个数字来说明人类语言之繁多，也说明公司多年来“让更多语言上网”的志向。谷歌的各项产品，各以其法，触及这片广阔天地的一部分。据该公司介绍，谷歌翻译支持将近250种语言，Gboard 手机键盘则支持900多种“语言变体”。这三个数字，量的是三样东西。翻译里的一种语言，意味着有一套可用的翻译服务；键盘里的一种变体，是一种输入设置，同一语言的各地说法，在键盘上可以分列成几项；七千余种，则是对世界语言总貌的估计。拿其中一个去减另一个，会得出一道看似齐整的“缺口”，证据对此却支撑甚弱。三者宜并排而观，当作三张各自独立的快照，看数字工具眼下伸展到了多远。

博物馆为这场展览定下的主题，是语言与权力、身份、社会之间的牵连。博物馆官网列明，展期至2028年2月27日，开幕原定于2026年11月5日（星期四）晚上7时。谷歌11月9日的文章，则把开幕放在发文的当周。两说相参，时日仍悬：博物馆所记为计划之期，谷歌的措辞只约略指向11月9日前后数日，开幕究竟在哪一天举行，两方资料都有待确证。谷歌又称，展览日后将移师法兰克福，据该公司所述展至2029年9月；法兰克福的确切日期，仍待第二个来源核实。

网站上可做的事，官方写得明白，也很简单。人可以在搜索框里键入一种语言、一个国家或一个地区的名字；也可以拖动地图，点开一枚图钉，读到那枚图钉所代表的语言的资料页。这一页把好几类信息收拢在一个整洁的面板里。一个问题随之而来：这块面板究竟知道些什么，每一行字又从何而来？

## 图钉背后的卡片

答案要从一个听来艰深、细想却很平常的词说起。LinguaMeta 所存的是“元数据”，意即“关于某物的资料”。落到一种语言身上，它包括语言的各种名称、用以识别它的官方代码、说这种语言的人数估计、书写它的文字、使用它的地方、它在某处享有的官方地位，以及它的濒危程度。这座资料库所记的，是对语言的描述。语言本身——那些交谈、歌谣、故事与语法——则活在说它的人中间。

不妨借一个日常的比方，让这层意思落到实处。想想老图书馆里的卡片目录。每张卡片告诉读者书名、作者、年份和书架编号。卡片帮人找到一本书，也帮人分辨两本相似的书，书本身则静静立在架上。倘若一张卡片的出版年份一栏空着，那本书依旧在；只是编目的人当时缺了这一项。倘若卡片打字于1980年，上面的内容便反映图书馆在1980年所知。LinguaMeta 的样子，大抵就是一套极其庞大的语言卡片目录。这个比方也有它的边界，值得说清：一本书在两次借阅之间纹丝不动，语言却随着说它的人生活、迁徙、婚嫁、流转、造出新词，而时时变化。一张记录活语言的卡片，是对一样流动之物的一次定格。

这些卡片，出自许多人之手。网站的常见问题页称，LinguaMeta 汇集并“协调统一”了19个被引用来源的信息。所谓协调统一，是把名称、代码、格式各异的记录对齐，使它们以同一种形态描述同一种语言。19这个数，数的是为这道合并工序供料的参考资料集。每一个资料集各有来历：各自的研究者，各自的调查年份，各自的取舍判断。十九个来源，描述的是一个汇编的过程；它们是多年旧作的合集，其中条目的年代与方法，可能各有差异。

LinguaMeta 还记下每条信息的出处，研究者称之为“来源记录”或“溯源”。溯源好比图书卡片上的一枚印章，标明每一项细节由哪一套旧目录提供。有了它，细心的读者便能循数字之源而上，加以查考。循源所得，是一个数值的来处；这个数值如今是否仍然准确、仍合时宜，还要拿原始来源和更新的证据再作核对。

这座资料库也有它有意划定的疆界。存放 LinguaMeta 的代码与数据仓库，设在公开平台 GitHub 上；仓库说明写道，其着眼点是仍在使用的口语语言。许多人造语言（即个人或群体刻意创制的语言）、许多手语、许多历史语言，都在这一范围之外。因此，这幅地图呈现得最完整的，是当今人类语言中口说的那一面。

即便在疆界之内，卡片的填写也深浅不一。仓库的说明文件（README）称，LinguaMeta 收录的语言中，约有83%具有使用人口数值。这个百分比有它特定的分母：资料库自身所收的语言。它衡量的，是某一栏在资料库条目中被填上的频率，说的是一个字段的覆盖程度，与世界人口的占比、普查的准确度，各属一事。其余的条目，约六分之一，使用人口一栏是空白。空白之处，其数待考——一如卡片上空着的年份：编者手头缺这一项，而那种语言和说它的人，依旧在世间生活。说明文件还提到，另有一些字段，填写得比使用人口一栏更稀疏。

至于已经填上的数字，说明文件也交代了它们的取整之法。人口数取自原始来源记录，取整的步幅随数字大小而定：一个数落在哪一段区间，便由那段区间决定用哪一级步幅。一百以内的数，照原样记录；一百到一千之间，取整到十位；一千到一万之间，取整到百位；依此类推，数越大，步幅越宽，到了一千万以上，便取整到百万。区间只用来挑选步幅，记下的始终是单个的数，其精细程度与数的大小相称，免得一个庞大的估计，看上去比它的来源更精确。放回卡片上看，就像一本厚书在页数一栏写下“约三百页”，一本十二页的小册子则照实记下页数。资料库还会把一种语言在多个国家与地区的使用人口加总成一个总数，并设法避免同一批人被计算两次。说明文件提醒：这类计算，可能放大原始来源里已有的误差。倘若两条底层记录各带一点小错，合成的总数便把两处错都一并带上。

濒危标签，也是同样的道理。据说明文件，这些标签采用一套六级量表，源出联合国教科文组织（UNESCO）的《世界濒危语言地图集》，说明文件引用的是该地图集2010年的参考版本。教科文组织是联合国主管教育、科学与文化的机构，它的地图集把语言排在一道阶梯上，一端是“安全”，另一端是“消亡”，所依据的主要是语言在父母与子女之间代代相传的情形。2010这个年份，标明的是所引的那一版地图集。具体某个标签背后的观察，可能来自不同的年份，各条观察的确切日期，资料中留作开放。2026年屏幕上显示的一个标签，反映的是那份参考资料及其底层来源；把它读作2026年新近完成的评估，便是把一枚承袭下来的标签，当成了一次新的测量。

还有一桩更细微的事：什么才算“一种语言”？LinguaMeta 既收录单个语言，也收录“宏语言”，即把几种单个语言收拢在一起的更宽泛的伞形分组。用卡片目录来说，宏语言像是一部多卷本套书的总卡，与每一卷的分卡并排归档。两种卡片都有用处，而把总卡与分卡相加的计数，会把部分内容算上两遍。说明文件提醒，混合这两类的计数可能重叠。说明文件在介绍收录范围时又写明，单个语言之下更细的变体，例如地方方言，目前整体落在 LinguaMeta 之外；这套目录收到单个语言这一层为止。每一道这样的界线，都出于一次实际的归档决定。一种语言止于何处、另一种始于何处，说话的人与学者之间时有分歧，而这些分歧里，往往牵着历史、政治与尊严。数据库里的一个标签，记下的是编者所作的归档选择；更广的讨论，仍在相关的人们中间继续。

另有两个词，有助于读懂一页资料。“文字系统”（script）是一套书写符号，比如本文英文原版所用的拉丁字母。“语言环境”（locale）描述一种语言被使用时所处的地理或文化背景。说明文件举了一个例子来说明这几个维度各自独立：在印度以古木基文（Gurmukhi）书写的旁遮普语。这个例子挑出一种语言、一种文字、一个地方，用来显示数据库如何把三个维度分开存放。旁遮普语本身用多种文字书写，也通行于多个国家；例子只是为求清楚，取其中一种组合。

地图，亦当如是看待。每一枚图钉，标记的是一个记录在案的坐标，即由经纬度确定的一个点。用一个点把一种语言放上屏幕，十分便利。而说这种语言的群体，却散布于山谷、城市，以及离乡远居的侨民之中。图钉所定的，是一个参照点；至于一个群体分布的全貌、它的故土所在、某个国家对一种语言的主张，其所关者，属于另一类证据。

对下载数据的人而言，还有一处细节要紧。仓库以两种格式提供资料。完整版用 JSON，一种把细节层层嵌套的结构化文件格式；精简的总览则是 TSV，一张以制表符分隔各列的简单表格，用电子表格软件便能打开。据说明文件，精简表格省去了完整文件里的若干细节，包括部分来源记录、扩展名称、说明文字如何使用的标签、经过考证的官方地位，以及坐标。研究者在表格里看到空白的一列，应当先去查对完整文件，再判断整个资料库是否缺少这项信息。授权方式也是混合的。谷歌研究院自身的材料采用“知识共享署名4.0”（CC BY 4.0）许可，注明出处即可再用；来自外部的组成部分，则各依其不同条款。凡打算再利用这些数据的人，须逐一查明各部分的条款。

## 一扇门，与门上的小字

至此，展览的大主题与这座数据库相遇了。把数千种语言铺在公共博物馆里一幅发光的地图上，是让它们被人看见。围绕一种语言的数字工具，各有各的用途：研究数据库为研究语言的人整理事实；手机键盘帮说话的人用母语打字；翻译工具帮人把意思从一种语言带进另一种语言。它们各有各的要求。资料对这几样工具分别作了描述，至于彼此所费工夫孰轻孰重，资料里留着一片空白，有待日后比较。一种语言的生命力，语言学家称之为“活力”，又系于另一层：有人在家里说它，有孩子学它，有群体在工作、礼拜与歌唱中用它。

本文所查的公开资料，描述的是这件装置和它的工具。观众从中学到什么，此后语言的教授与使用起了怎样的变化，这些问题落在那几页资料所载的范围之外；相关证据若有，须往别处寻访。谷歌还提到 Project Vaani 与 Project Waxal 两项计划，它们分头收集口语录音，是各自独立的项目；这些录音是否出现在语言探索器之中，本文所查的公开资料留作开放。谷歌表示有意与各语言群体合作，这是一种所述的做法。每个被收录的群体对自身条目的审阅与认可程度如何，在这些公开资料里，仍是一道悬而待解的问题。

这个工具，确有一套直指“卡片有瑕”的机制。网站邀请使用者提交附有来源依据的反馈；团队先行审阅，再对仓库或网站作相应修改。常见问题页说明，每逢数据集有重大进展，便会定期更新——这是一种间歇的节奏，止于持续的实时刷新之前。换成图书馆的说法，就像前台放着一叠纸条，读者可以写下某张卡片上记错的年份，馆员核实之后再重新打字。这一设计，在道理上说得通。网站与仓库所载的，是这套流程本身；有多少建议送来、多少获得采纳、修改多快出现在屏幕上，这些数字落在那几页公开资料所载之外。

于是，柏林这件装置同时给出了两样东西。它为公众开了一扇引人入胜的门，通向人类言语的万千样貌；它也带着把数千种鲜活实践装进整洁卡片时必然伴随的种种简化：按大小分级取整的人口数，系于2010年地图集参考版本的濒危标签，关于伞形分组及其下方言的归档选择，以一个点代替整个群体的图钉，以及约六分之一空着的人口栏。审视这些选择的工具，就在同一个项目之中：来源记录、公开的说明文件，以及一条凭依据提出更正的渠道。

尚待一观的，是屏幕能否把它的空白，显示得与图钉一样分明。当柏林的一位观众轻点一个圆点，读到整整齐齐的一页，那一页是否也会告诉他：哪几行是估计，哪几行已经陈旧，哪几行出自一次归档决定——而一位更知底细的说话人，又该循何路径，帮忙把记录改正？

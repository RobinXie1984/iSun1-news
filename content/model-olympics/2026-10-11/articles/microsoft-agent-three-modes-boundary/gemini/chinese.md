《牢笼无影，神机何往：微软“执器容器”缚灵考》

天地有大巧，造化无尽时。近世以来，人工智慧如日方升，神机独运。算力所至，能裁千言、运万码、筹百策，若有灵思。然灵机既启，缰绳安在？世人方惊叹其鬼斧神工，旋即忧患其反噬之祸。譬如放鹿于禁苑，授剑于幼童，若无轨度，祸患立至。

丙午年九月初十（二〇二六年十月七日），微软布告天下，谓“微软执行容器”（MXC）已达普遍可用之境。此事收集于九月十四日（十月十一日），非今日之新发。然此乃厂商一户之言，非第三方独立安全核查之明证。

【立规外设，画地为牢】

夫 MXC 者，盖无形之牢笼也。操盘之人、设防之企，于智能傀儡掌控之外，立规设限，定其可揽之册、可通之渠。灵机虽巧，不得自增其权，亦不得擅越藩篱。

其底座所依，各有差池：进程隔离，兼通 Windows 11、macOS 与 Linux；会话隔离，仅限于 Windows；若夫微型虚机（MicroVM），则尚在试运行之域，属实验之列。至于更深之企业身份与管理整合，微软许以未来，尚未全数交付。

【三态幽微，纵阻互见】

最堪玩味者，乃其所设三态，静动互异，微旨幽深：

一曰强制模式（Enforcement）。逢未授权之举，雷霆一击，立时阻绝，不留残迹，无报告之烦。

二曰学习模式（Learning）。遇非分之求，阻绝如故，然悉数录其行径，以为后来规诫。

三曰宽容模式（Permissive）。此乃最奇诡之处：虽有逾矩之举，却听之任之，放行其过，仅记录在案。虽系统原有之藩篱仍在，然“记录”绝非“阻绝”，听任之余，患隐于未然。Windows 专有之进程容器活动报告，虽能助立规者完善法度，然记录试图，非阻其行也。

【示警于册，未敢言安】

观其公开代码库（microsoft/mxc） README 示警，言明若以 --audit 巡查模式运行，则沙盒之防洞开，绝不可运行未信之码。虚机底座尚属实验，虽有通用（GA）之名，非谓诸般底座皆已成熟，亦非谓一切规矩皆无瑕疵。

世人切勿以为一容器既出，万患皆消。此非已知之漏洞泄露，亦非万全之护军。其抗击攻伐之能几何？用者几何？减患几何？皆未可知也。深邃之域，仍待探索。

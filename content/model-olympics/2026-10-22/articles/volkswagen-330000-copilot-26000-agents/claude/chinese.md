大众三十三万人配 Copilot 记
标题三则

一、悬念：《三十三万之众，二万六千之"灵"，一问至今未解》

二、情感共鸣：《举厂同得一AI为伴，孰来断其果有裨益乎？》

三、反直觉：《大众最巨之数，乃最不足凭之数》

正文
序：一纸之数，声闻四海

公元二〇二六年十月二十一日，微软发布企业新闻稿一则，其辞曰：大众汽车集团已为逾三十三万员工配备 Microsoft Copilot。

其数浩大，整齐悦目，便于口耳相传，宜于会上称引。闻者遂谓百年车业巨擘倾力向智，蔚然成风。

或诚如此。然此数所答之问，实狭于其所示之象。

此数言公司自称授以门径者几何，而未言用之者几何、用之几勤、所用何事，亦未言其业因此而精否。

门者，可入之所也；足迹者，已入之证也；所至之境，乃其价值也。 新闻稿所陈，一曰门数，二曰别廊之足迹，三曰对彼岸之殷殷期许。今逐一辨之。

其一：原稿所载，据实而录

以下诸事，皆出于微软二〇二六年十月二十一日企业新闻稿，乃供应商述其客户部署之言，非独立审计之论。

事一，配备逾三十三万人。 微软称，大众集团已为逾三十三万员工配备 Microsoft Copilot。

事二，Copilot Chat 月活逾三十万。 据新闻稿，其部署分阶而行，始于广开 Copilot Chat 之门；于该平台之上，大众见月活跃用户逾三十万。

事三，Work IQ 行于诸部，智能体逾二万六千。 微软称，员工今以 Copilot 结合 Work IQ，用于工程、生产、采购、销售等域；过去一月之内，集团上下活跃之智能体逾二万六千。

事四，二位主事者，言其所望。 新闻稿引二人：大众集团数据与人工智能主管 Sophie Vassarotti，及微软德国管理委员会主席 Agnes Heftberger。二人所述，皆关乎提效与速决之期许，及公司自身之评估。据所呈简报，稿中未载可量化之提效百分比、节省之费、增收之额、错误之减、基线、样本或对照之比。

事五，来日方长，更图远略。 两家有意扩大合作，推展"智能数据基座"（Intelligent Data Foundation）。据稿所述，此乃大众建于 Microsoft Fabric 之统一数据生态。其合作列于十月二十二日科隆 Microsoft Frontier Tour 之议程，稿中具名一场，定于欧洲中部夏令时上午九时。此乃日程所载，非谓其会已行，亦不知其间所言。

自此以下，皆为笔者之论析，非原稿之事实。

其二：三数三问，不可混同

观此类宣告，最易之误，在于以诸巨数为一事之脉络。然此三数，各量其物，泾渭分明。

三十三万者，供给之数也。 言公司所配之人，不言人人皆持全额付费之许可，亦不言人人尽用诸般功能、月月开启。"配备"二字，乃就供给而言。

三十万余者，用量之数也，且限于一品。 所计乃 Copilot Chat 之月活跃用户，即部署初阶广开之层。其与三十三万之数，产品层级有别，时段或亦不同。

故有一算，切不可为：以三十万除以三十三万，得"约九成一之采用率"。此乃以一品之月用量，除以更广之配备数，混淆分母。况二数皆为约略之辞（"逾"”以上"），稿中亦未言其同出一源。数出异廊，相除无义；强为之比，徒乱视听。

二万六千者，智能体之数也，而"智能体"三字，所负甚重。 微软称过去一月活跃者逾二万六千，然简报未明：

何者谓之智能体；
其数为独立之体，抑含重复变体；
所司何事；
自主几何；
成事几许；
人工核准之频；
产出之优劣。

此非二万六千数字之工，非以其代二万六千人，亦非AI独掌产线、驾驭车辆之证。不过是一月之内活跃之软件配置，其定义未尝示人而已。

先点其数，再问其功。

其三：可得与有用，相去几何

此乃全篇之枢要，亦不独大众为然。

一工具遍及如此之众，何以分辨"人人皆有"与"确有实功"？

试设三家公司，所宣相同：

甲公司，人人得用。多数人启之一次，令其撮要一信，旋即故步自封，复归旧辙。
乙公司，人人得用。少数精熟者，借之重构若干苦差，如供应商文书、工程变更摘要、销售方案初稿，诸事显著提速。
丙公司，人人得用，日日勤用。后察其产出多需人工改正，净益甚微，事倍功半。

三家皆可据实宣称"我配备若干人"”我月活若干人"，而观者无从由此数辨其属甲、属乙、抑或属丙。

此皆假设之辞，非言大众如何。要义在于：所报之数，不足以别此三者。此非苛责大众，乃述其所公布证据之性质；当今企业宣告AI，大抵如是。

许可者，诺也，非证也。

其四：主事者之言，及其所未言

稿中所引二位，一掌大众集团数据与AI，一主微软德国管委会。据简报，其旨在于提效与速决。

当视之为部署主责者之意图与内部评估。此非谓其言失实。领导者常握不入新闻稿之实据，如内部调查、试点结果、团队反馈之属。

然述其价值，与量其价值，判然两物。据简报，稿中未见：

提效之百分比；
节省之金额；
收入之影响；
错误率之变化；
基线之期；
样本之数；
未得此工具之对照组。

于此有二谬论，皆甚诱人。

一曰**”已证其效"**。简报中无一量化结果可为之佐证。

二曰**”必无其效，否则何不示数"**。此亦不然。公司常因竞争、合约、方法之故，秘其成果数据而不宣。未报者，未必无也。

可守之论，平淡无奇：此源之中，成效之证尚未公布。 凡以回测为业者，当觉似曾相识。头条指标光彩夺目，而无样本外之检验，则不过假说而已，未成定论。

安全之辞亦然。稿中所称"安全"”可信"，乃两家自述，非独立安全审计之结论，亦非其有隐患之证。据此简报，无凭可言监控、泄密、裁员或软件安全之失；若强言之，乃捕风捉影，非论析也。

其五：数据之基，方为暗流

稿中最不夺目之一句，五年之后，或最见分量：两家有意推展**”智能数据基座"**，据述乃大众建于 Microsoft Fabric 之统一数据生态。

何以重于人数？

车企之AI助手，其用之广狭，系于其所能及之物。只能代拟书信者，不过便利而已。若能触及治理有方之工程、采购、生产、销售数据，且权限与管控皆稳固，则近乎基础设施矣。

然须细察其时态：此乃意图，非已于全集团贯通之功；所述者乃行进之方向，非既成之舆图。今日大众之数据，统一几成，质量几何，权限何如，简报皆未载。

席位者，AI部署之显者也；管道者，其隐者也。席之可坐与否，系于管道。

其六：欲服疑者，当示何证

或为采购者，或为投资者，或为员工，或为同业，欲穿透此类宣告之表，下列披露，可使证据由"可得"进于"有用"。简报中皆未见之；然未见非谓其无，但未示人耳。

一、用之深，而非仅其广。 周活跃、人均会话、数月之留存，并按产品分列（Chat、Copilot 结合 Work IQ、智能体）。

二、明定智能体之籍册。 何谓智能体，独立者几何，每步需人工核准者几何，上月成就实事者几何。

三、分部之成效，并有基线。 譬如某一采购流程，前后周期以同法量之。

四、对照之组。 后用或未用之团队，以别其功于时令、改组或一时之顺遂。

五、质量与修正之本。 AI 产出原样可用者几成，稍改者几成，弃置者几成。

六、独立之验证。 由供需双方利害之外者，或审计，或学术研究。

此即核心之问之实答：有用之证，在于成效，对照基线而量之，由无利害者为之。

其七：不独大众，时势使然

企业AI已入一新境：规模之宣告，其成本甚廉；成效之证据，其代价甚昂。供应商欲示其势，客户欲示其新，二者之欲，交汇于新闻稿之中。

然此不足以谓大众之宣告空洞无物。使一工具达于数十万人之前，分阶推行，且于对话层见大量月用，若诸数属实，诚为运营之壮举。信其所述之所为，未为过也。

所需者，乃一习惯：每见一言，必配其证。

"配备三十三万人"，供给之言也，可据而报。
“Copilot Chat 月活逾三十万”，一品之用量也，可据而报，然须明其范围。
"上月二万六千智能体活跃"，活动之言也，其名未定，可报而须标其义。
"此令我更速更效"，评估之言也，当以评估报之，以待量化之实。

当此AI之世，最贵之技，或非善于提示，而在见一数而问其所量何物。

结语数则
配备非活跃，活跃非有效。 三言三证，各有其责。
数出异廊，勿相除之。 三十三万与三十万余，所量各异；由此生出之"采用率"，皆向壁虚造。
智能体之数无定义，则为标题，不为指标。
主事者之乐观非证，证之缺亦非败之证。 诚实之论，唯"尚未示人"四字。
观其数据之基，勿唯观席位之数。 推展之计虽属意图，然长远之价值，当出于此。
君其试言

若许君向大众与微软索取一项附加指标，非功能之列，但一明确定义之数，何者可使君信此三十三万席位所生者为实功，而非徒设之器？

用之深度欤？智能体之籍册欤？抑或一事前后之比较？或别有所见？

愿闻高论，共析其理。

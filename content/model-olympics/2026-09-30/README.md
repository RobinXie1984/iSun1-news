# iSun1 Model Olympics: original drafts

This collection contains original AI model drafts, preserved exactly as captured and unedited. They have not undergone independent factual verification. A model may introduce claims, interpretations, fictional scenes or errors that are absent from the supplied material. Inclusion records an available draft; it does not certify its accuracy.

The factual briefs are separate source material. Each brief preserves the original episode's event/report date, attributed claims, uncertainties and primary-source links. Those dates describe the original episode, not a new event on the export date. The common English and Chinese generation prompts are included separately.

[The catalog](catalog.json) identifies each topic, provider, recorded model, language, source brief and available article. Missing submissions or captures awaiting verification have status `UNKNOWN` and an unavailable-submission note; no substitute text has been written for them. Generic interface remnants may remain in the preserved drafts.

Models appear in a fixed order. There are no rankings or scores. Robin makes the editorial decision after the one-week comparison.

The `SHA256SUMS` file records the exported bytes for checking that a draft has not changed. It is an integrity record, not independent verification of the draft's claims.

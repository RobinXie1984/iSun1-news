# Jensen Huang and Satya Nadella bring local agents to Windows PCs
Event date: 2026-10-07. Collection date: 2026-10-08 (Hong Kong).

Verified source claims:
[P1] NVIDIA reports Jensen Huang and Satya Nadella outlined Windows PC hardware/software co-engineering at the October 7 Microsoft event in San Francisco. RTX Spark laptop preorders opened, with availability October 16; compact desktops are planned for November.
[P2] NVIDIA describes RTX Spark with up to 128GB unified memory and up to one petaflop FP4 AI compute. These are configuration/precision-qualified vendor specifications, not observed universal speed or independent tests. DGX Station for Windows was previewed separately; its much larger memory is NOT laptop memory.
Source P1-P2: NVIDIA, October 7, https://blogs.nvidia.com/blog/local-ai-rtx-spark-microsoft-windows-event/
[P3] Microsoft describes hybrid local/cloud intelligence, permission-based local context/actions, and Microsoft Execution Containers generally available on Windows 11. HydraFusion local/cloud routing is scheduled for experimental preview later in October; Copilot hybrid features roll out over coming months.
[P4] Microsoft says Surface Laptop Ultra supports up to 128GB memory and models exceeding 120 billion parameters locally. Surface Ultra availability begins October 16. This is not proof every model/configuration works offline, or that purchased hardware eliminates cloud fees. Vendor benchmark gains are workload-specific, not measured here.
Source P3-P4: Microsoft, October 7, https://blogs.windows.com/windowsexperience/2026/10/07/building-windows-for-hybrid-intelligence/

Editorial tension (analysis): paying for local hardware could replace some metered inference, while permissions, maintenance, model capability and cloud routing remain consequential. Do not invent a purchase price, universal savings, private CEO motives, or a claim the cloud is obsolete.

三种标题

悬念：Claude 竟令 Git 不堪重负？Anthropic 七人五月，另铸新器

情感共鸣：自成其功，反受其困：Anthropic 弃 Git 另铸之记

反直觉：AI 之瓶，不在写码，而在纳码

正文

西元二零二六年十月十三日，Anthropic 有报；十月十四日，采录成文。所载皆其内部之数，非独立核验之准。原文出处，见文末。

一、瓶移

夫世之论 AI 者，多言其速成代码。然速成之后，纳之者谁？

昔者软件之史，皆以写码为急。IDE、框架、云 CI、微服务，层层迭起，皆欲缩思与 commit 之距。Git 居中，如江河之床，不显其功，而万物赖之。及 AI 至，星河倒泻，春潮带雨，旧堤顿显其短。

Anthropic 自述：其内部五月，日并约二千五百码更；至九月，逾三万。源控之队断曰：基建为瓶颈。此言甚奇。盖二十年来，众人皆以写码为苦，今写码之势如破竹，而纳码之机反捉襟见肘。

故曰：AI 非但速写，亦改纳码之律。

二、数破旧念

据 Anthropic 自述，五月日并约二千五百，九月逾三万。四月之间，增十二倍。此其内部之数，非独立核验之准。

源控之队不谓码劣，不谓人怠，而谓纳码之机为限。此乃本末倒置之反转。写码易，纳码难。审查、CI、合并、人目之注，皆有限也。AI 使写码之费大降，而使纳码之费反升。何以？量增而人目不增。水涨船高，而岸不移；潮涌愈急，而闸门愈窄。

七人小队，造 Scion，又造审阅之器 Antique，及诸相关系统。五月之内，尽迁其 monorepo 离 Git。七人五月，monorepo 之迁，此语几不可信。凡历大库者，皆知迁 monorepo 如开胸而跑马拉松。然据其自述，事竟成。Claude 既助成其劳，亦助铸其替。人匠仍导架构，仍审变更之意。

此句重。非谓 AI 自噬，非谓工程师见逐。材料明戒：多并不证码质，不证盈利，不证工程师见汰。七人者，专注之证，非替人之证。

三、Scion 何物，非何物

Scion 之用，在线客户端、服务器端操作、稀疏按需取数。Anthropic 报：较旧 Git 镜像，CPU 与内存基建足迹小二百倍；CI 之 CPU 容量得二成五之益。然此二数各有所指，非谓总费省二百倍，亦非谓处处快二百倍。二百倍者，基建足迹也；二成五者，CI 容量也。不可混一。

其旨明矣。旧模：全库镜像，处处克隆，重操作在每端。此适于变更少之时。三万日并，则每操作皆税。Scion 稀疏按需，赌不必全世在每案。需者取之，及时而至。此乃一病一答，非万灵之药。

Anthropic 明言：Scion 非通用 Git 之替。其劳异常，其内部 token 之费异常庞大。未有公开即插即用之发布。故“Anthropic 弃 Git”不可读为“Git 已亡”。Git 仍为众用，根深蒂固，不可撼动。Scion 乃特病特药，非普世之方。

然其示一模式：系统成瓶颈，则优化或替之。Anthropic 择替。替唯劳极者可。常人仍宜优 Git 流、CI 缓存、减审迟。未雨绸缪，量入为出，方为常道。

四、未言之争

AI 使写码廉，未使纳码廉。反使纳码贵。量增而人目恒。此乃 Anthropic 源控队所识。非 Claude 写劣，乃写多而纳机为限。可增人，然 Anthropic 铸机。

此选，诸组织将遇。AI 愈能，变更愈多，审队愈长，CI 愈紧。写与并之沟愈宽。胜者，以纳码基建为一等工程，非后思。一叶知秋，见微知著。今日 Anthropic 之瓶，明日或为众人之瓶。

又有文化之维。输出增，则喜输出。“月并三万”如胜。然多并非码质、非盈利、非除人之证。唯证系统纳更多。此 Anthropic 报明。不称 Scion 使码更佳，称 Scion 使基建可行。二者异。非“码好二百倍”，乃“基建足迹小二百倍”。别。

五、未知之域

未知者：性能独立复现、全盘经济、他处适用。其劳与 token 费异常。彼可行，他未必。亦未知长久维护。五月造源控可奇，五年维持则另一事。每自制系统积复杂，每特解依其队。Anthropic 未言如何久持，未言开源。亦未知三万日并为永平或更高之途。AI 若进，量或更增。Scion 或为今日之瓶，非明日之瓶。

不可妄传：Dario 之语、Git 之宕、工程师之逐、Git 普亡，皆无据。事实归事实，推想归推想。此乃采录之则。

六、一语难忘

AI 非但写码，且改写纳码之律。

七人非欲替 Git，欲追 Claude。替者，果也，非的也。基建之变常如此：非大宣言，乃静觉旧管不任新压。Git 未亡。Anthropic 明言。然 Git 非每劳之顶。于 Anthropic 之量，顶已移。于余人，问简：若明日产出三倍，汝之基建能存乎？抑汝为瓶颈？

沧海桑田，舟楫须易；星槎既远，旧渡难支。瓶颈未消，只移耳。

若 AI 助手明日起月并十倍之码，汝开发之管，先坏何处？

标题三则

悬疑之题： 《三百二十二日，一朝挂印；扎克伯格，候之久矣？》

动情之题： 《功业未半，忽闻召唤：一位掌门人的十一月》

反常之题： 《不购其国，独取其将：Meta 此举，胜于并吞》

三百二十二日记

刊于二〇二六年十月四日。事在九月二十八日，此为追记析论之文，非当日新闻也。

序

世之为一司之长者，多以岁计；此君之任，以日计耳。

三百二十二日。

二〇二六年九月二十八日，两纸公告同日而出，一事两面，遥遥相望。

其东，Meta 宣言：CJ Desai 将任首席企业平台官，直隶于马克·扎克伯格。

其西，MongoDB 宣言：Desai 即日去职；前任执事 Dev Ittycheria 复归，权摄其位，董事会别求长才以继之。

一家得将，一家迎旧。一去一来，风云乍起。

今且据实而录，析其所是，辨其所非，而后问其所未可知。

一曰：据实而录，不饰一辞

欲论其事，先正其实。

Meta 之所宣（二〇二六年九月二十八日）：
其公告署扎克伯格之名，命 CJ Desai 为首席企业平台官，直接向扎克伯格禀事。Meta 方启企业人工智能平台，所列初始之品凡四：Muse agent、Meta Business Agent、Muse API、Muse Code。

MongoDB 之所宣（同日）：
Desai 即刻离任；前执事 Dev Ittycheria 出任临时执事；公司另觅正任之人；既有季度、年度之业绩指引，重申如故。

时序之考：
MongoDB 于二〇二五年十一月三日公告，命 Desai 为执事，十一月十日生效。自是日至二〇二六年九月二十八日，凡三百二十二日，未满十一月。

然须明言：三百二十二之数，乃吾以两日相减而得，非二家所自言之任期也。

其所未言者：
无聘价，无俸禄，无保底之企业营收，无客户之约。

此末一条，与前三者同重。读者宜谨记之。

二曰：辨其所非，以绝流言

未及论断，先扫三说之妄。此三者，坊间或乐道之，而原文无据。

其一，非并购也。
Meta 所聘者，一人耳，非一司也。MongoDB 自有其董事会，自有其临时执事，自有其指引，依然独立。聘其将，不即得其国；延其庖人，不即有其酒肆。

其二，非竞价之战也。
未见他家争聘之证，未闻折冲谈判之辞。若有人言之凿凿，当问：出自何典？

其三，非已成之业也。
Muse 诸品，乃 Meta 新启平台所列之初品，是为谋划、是为阵容，非营收也，非市占也。成与不成，今不可知。

一言以蔽之： 大事之公告，其所不言者，往往重于其所言。

三曰：析其义理（以下皆吾臆论，非报道也）

自此以下，乃作者据上述事实之推演与评说，属一家之见，非原始报道之实。

其人何故舍印而去？

吾不知，二公告亦未言。凡言其心事者，皆揣度耳。

然可论其形势，而不必窥其肺腑。

执掌上市之司，固一方诸侯；直隶于扎克伯格、总揽企业平台者，则另一番天地。前者如掌舵于既航之舟；后者如受命于新造之舰，舰未尽离港，而其主乃天下府库最丰者之一。

二者孰优，未可轻断；然其非一事，则昭然若揭。

一言以蔽之： "执事"者，名也；"直隶创始人"者，势也。有时势大于名。

直隶之制，所示何意？

吾欲于"直接向扎克伯格禀事"一语，重笔圈之。

大公司之中，汇报之线，即轻重之言。新设之职直通创始人，往往意在免其层层请示、预算掣肘、上呈迟滞。

此为吾之解读，非 Meta 所陈之理；其公告未释此制。然架构本身，不言而自明。

Meta 所缺者何？

此事之枢纽，乃一析论之问，非预言也：

以消费者之浩瀚流量，能否化为企业之深信笃用？

Meta 之根本，素在消费平台与广告。企业软件则另是一局，规矩迥异：

买主易矣。 庶民一点"同意"即可；企业则采购、安审、法审，甚或试用经年，其期或长于此君之任。
承诺易矣。 庶民可恕一时宕机；企业以智能体面对其客户，则不能容。
关系易矣。 消费之品，以广而胜；企业之品，以信、以约、以服务、以有人接电话而胜。

聘一甫掌数据库公司之人，观其职守，似押注于后者之能。此乃据其职位而推，非谓知 Desai 之具体筹划，Meta 亦未详言也。

一言以蔽之： 流量可得一见，信义方得续约。

观其品名

四品之名，可略窥其志之所向，然仅就其所宣而论：

Muse agent，似为通用之智能体；
Meta Business Agent，似专为商家而设，或倚 Meta 既有之商业关系，然本文所据之摘要未详其细；
Muse API，似供开发者构建于其模型之上；
Muse Code，似为编程之器。

吾读其名，非读其规格。名者，线索也，非契约也。合而观之，乃一平台欲兼顾商家与为商家造物之开发者。

一启而四面开阵，志气宏大；然四面受敌，守之亦难。

四曰：彼方之局

众论多聚焦 Meta，吾以为 MongoDB 一方，同具深意。

一司之长骤去，当日要务约有二端：一曰运转如常，二曰安抚投资之人。

MongoDB 为二事：

其一，迎前执事 Dev Ittycheria 复归，权摄其位。 旧识之人，非陌路之客。

其二，重申季度、年度之指引。 以白话言之：此番人事更迭，未改其财务展望。

此第二着，乃无声之号令。无论人心如何波动、战略如何推敲，公司择言："向所告诸君之数，依然有效。"

信与不信，在乎市场。然其辞令之策，一目了然：守常、守旧、守稳。

一言以蔽之： 骤失其帅之日，最能安人心者，莫过"吾之数未改"。

吾更有一私见，亦标明为私见：二〇二五年十一月方授印于新人，二〇二六年九月复归印于旧主。司犹人也，地动山摇之际，每思故人。物是人非，人去复来，亦一段沧桑。

五曰：三说并陈，各执一端

君素重诘难之审，今各立三说，皆尽其长，亦揭其短。无一可证。

甲说："Meta 志在企业，意甚坚决。"

其理： 若非欲争，何必设直隶创始人之企业首官，又同日推出具名之品？聘一在任上市公司之长，代价不菲，足见其志。

其弊： 有志不等于有成。大公司宣言进军企业者多矣，宣言者，易事也。

乙说："此乃人才之争，非市场之争。"

其理： 巨擘之间，争揽干才，于人工智能尤甚。此事或更多映照用人之市，而非某一企业战略。

其弊： 忽视其人与平台同日而至、诸品具名而列。时机相系，人与品不可分。

丙说："消费之基因，难成企业之功。"

其理： 企业之主，重可靠、重数据之处置、重服务、重长约。以流量立身之司，或遭疑虑；一人之聘，难改积习。

其弊： 司亦能变。直隶创始人之制，正为推变而设。首日唱衰，与首日叫好，同属轻率。

吾之实见：三说皆有其理；然就二〇二六年十月四日所见之证，不能定其孰胜。言之凿凿者，是预言，非报道。

一言以蔽之： 发布之日，凡策非神即愚；待四季之后，方知其为何者。

六曰：来日所当观

欲以证据评此事，而非以意气，吾列一观察之单。以下皆吾欲观者，二家未尝宣告或承诺。

于 Meta 一方：

具名之客户。 非泛言"商家"，而是明列某机构公开采用 Muse agent、Meta Business Agent、Muse API 或 Muse Code。
定价与条款。 企业之品，存亡系于商约之明。
开发者之采用。 Muse API 与 Muse Code 之成败，在乎开发者是否真筑其上。
可靠之承诺。 枯燥之事，正是企业之事。
所披露之成绩。 日后 Meta 若择而公布营收或用量之数。

于 MongoDB 一方：

正任执事之觅。 何人，几时。
指引能否兑现。 重申指引，是为允诺；财报所呈，方为凭据。
Ittycheria 之姿态。 守成而已，抑或重整乾坤？

读后续报道，有一简则：凡文中有数字、有引语、有动机者，当溯其源于原始公告；不可溯者，纵言之凿凿，亦作揣测观之。

一言以蔽之： 读商业之题，最要一问：谁之言也？

七曰：大义所在

去其人名，观其骨架（此亦吾之所framing，乃一家之言）：

一家流量浩如烟海之司，欲得另一类主顾。不愿徐徐图之，乃延一曾坐上市公司首席之人，置于创始人之下，同时发其诸品。

其失帅之司，则反其道而行之：不作惊人之举，迎回故人，重申其数。

一方买其速，一方买其稳。

二者皆合乎理。孰能历久弥坚，唯待岁月验之。

此即三百二十二日之真意：非一任戛然而止之憾，而是两家于变局之中，各择所重——一者趁势而上，一者守常不移。

一言以蔽之： 商海之中，速与稳皆为策。其失，在妄图二者尽得、两全其美。

要略
实： 二〇二六年九月二十八日，Meta 命 CJ Desai 为首席企业平台官，直隶于扎克伯格，并启企业人工智能平台。
实： MongoDB 宣 Desai 即日离任，命前执事 Dev Ittycheria 为临时执事，重申业绩指引。
算： Desai 于 MongoDB 之任，自二〇二五年十一月十日至二〇二六年九月二十八日，凡三百二十二日（吾自算）。
未知： 酬金几何、动机为何、客户之约、Meta 企业平台成败与否。
论： 真正之试金石，在乎消费之广能否化为企业之信。
敢问诸君

吾有一问，今尚不能答，愿闻高见：

若君今日为其企业择一人工智能平台，Meta 须先证何事，君方肯以客户、以代码、以数据相托？

流量乎？可靠乎？定价乎？一位君所敬重之具名客户乎？抑或别有所求？

请言一事，足使君由"有趣"而至"签约"者。吾欲观诸君之答，更似庶民之所好，抑或采购之所审。

附注：标题中"候之久矣？"以问号作结，乃修辞设问，并无证据表明扎克伯格早有布局或长期等候，读者勿作事实观。
